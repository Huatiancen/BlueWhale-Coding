# ExpenseFlow 演示指令

## 主任务

> 阅读这个项目并加载适用的项目 Skill，找出所有失败测试的根因并修复。不要修改测试，修复后运行完整验证，并说明修改了哪些文件以及验证结果。

## 运行中追问

> 修复完成后，请分别说明数据解析、金额计算和报告生成三个问题的根因。

## 历史续聊

> 根据刚才的修改，总结这个项目现在如何保证退款和金额计算正确。

## 验证命令

```bash
python -m unittest discover -s tests -v
```

初始状态应稳定出现三个失败：退款记录被过滤、金额精度错误和完成率错误。修复后同一命令应全部通过。

正式演示前请复制一份干净目录，不要直接修改仓库中的原始样例。
